ddddocr 通用验证码识别工具

通用验证码识别工具

基于 Rust 构建，不依赖 OpenCV，跨平台运行，提供 REST API 与 MCP 协议

快速开始 API 文档 GitHub

核心功能

OCR 识别

支持多种验证码识别，内建官方模型与旧模型，可导入自定义训练模型

目标检测

416×416 anchor-free 检测器，返回边界框坐标

滑块匹配

模板匹配与像素差异比对，纯影像处理无需神经网络

MCP 协议

支持 Model Context Protocol，AI Agent 可直接调用

API 快速开始

通过 REST API 快速集成验证码识别能力到你的应用中

POST /ocr Content-Type: application/json
参数 类型 必填 说明
image string ✅ 要识别的图片，base64 编码（不要加 data:image/png;base64, 前缀）
png_fix bool — 为 true 时支持透明黑色背景的 PNG 图片
probability bool — 是否返回概率信息
length number — 期望的字符数，超过时丢弃峰值概率最低的片段
charset_range string — 限定字符范围。0-7 对应内建字符集，其他值为自定义字符集
color_filter string / array — 颜色过滤，例如 "red" 或 ["red", "blue"] 或 HSV 范围

调用示例

基础调用

curl -X POST "http://127.0.0.1:8000/ocr" \
     -H "Content-Type: application/json" \
     -d '{"image": "iVBORw0KGgoAAAANS..."}'

带颜色过滤

curl -X POST "http://127.0.0.1:8000/ocr" \
     -H "Content-Type: application/json" \
     -d '{"image": "iVBORw0KGgoAAAANS...", "color_filter": "blue"}'

指定字符长度与字符集

curl -X POST "http://127.0.0.1:8000/ocr" \
     -H "Content-Type: application/json" \
     -d '{"image": "iVBORw0KGgoAAAANS...", "length": 4, "charset_range": "5"}'

响应格式

{
  "code": 200,
  "msg": "success",
  "data": {
    "text": "Ab3x",
    "probability": null
  }
}
